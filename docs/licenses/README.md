# License texts

The files in this directory preserve the license texts that apply to
third-party components used by AlphaEnzyme:

- `Protenix_APACHE_LICENSE.txt` — Protenix (ByteDance), Apache-2.0.
- `OpenFold_APACHE_LICENSE.txt` — OpenFold dropout compatibility, Apache-2.0.
- `TorchDrug_APACHE_LICENSE.txt` — TorchDrug registry utilities, Apache-2.0.
- `P2Rank_LICENSE.txt` — P2Rank, MIT.
- `ESM_3.2.1.post1_LICENSE.md` — ESM package license shipped with the tested
  runtime.
- `ESM_current_MIT_LICENSE.md`, `ESM_current_THIRD_PARTY_NOTICE.md`,
  `ESMC_current_model_card.md` — current upstream ESM/ESMC licensing pages.
- `ESMC_legacy_noncommercial.txt` — the Cambrian Non-Commercial License
  Agreement shipped with ESMC-600M at the time of the experiments.

The ESMC-600M foundation weights are not bundled. Users obtain them through
the upstream loader and must comply with the applicable upstream terms. See
`../THIRD_PARTY_NOTICES.md`.
